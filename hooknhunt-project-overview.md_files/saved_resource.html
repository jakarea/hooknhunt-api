🎣 Hook & Hunt - Project Architecture Overview

Quick Summary

Hook & Hunt is an e-commerce platform for fishing equipment with:

  • Backend: Laravel with 13 modular systems (Catalog, Orders, Payments, Affiliate, Admin, etc.)
  • Frontend: Next.js 16 with React 19, TypeScript, Zustand state management
  • Language Support: English & Bengali
  • Payment Gateways: EPS and SSL Commerz
  • Tech Stack: Laravel/PHP backend, Next.js/React frontend, MySQL database

Payment Gateway Integration

  • EPS Payment: Configuration at config/epsPayment.php

    • Gateway: https://pg.eps.com.bd/PG
    • Callback: PaymentGatewayController@epsSuccess()

  • SSL Commerz: Configuration at config/sslcommerz.php

    • Gateway: SSL Commerz payment gateway
    • Callback: PaymentGatewayController@sslCommerz()
    • Status update: Sets payment_status to 'paid' in database

Payment Flow (Critical)

  1. User selects payment method (EPS/SSL Commerz)
  2. Order created via api.createSalesOrder()
  3. Payment initiated: api.initiateEpsPayment() or api.initiateSSLPayment()
  4. Backend returns gatewayUrl
  5. Frontend redirects: window.location.href = gatewayUrl ⭐
  6. User completes payment on gateway
  7. Gateway calls backend callback
  8. Backend updates order: payment_status = 'paid'
  9. Backend redirects to /order-success?payment_status=paid&order_id=123
  10. Frontend clears cart on /order-success page

Important Hook: usePayment.ts

  • initiatePayment() - Call backend to initiate payment
  • redirectToGateway() - Redirect to payment gateway
  • initiateAndPay() - Complete payment flow

API Integration (lib/api.ts)

Axios instance with:

  • Base URL: Backend API
  • Default headers: Content-Type, Authorization token
  • Error handling: Standardized error responses
  • Key endpoints:
    • createSalesOrder() - Create order
    • initiateEpsPayment() - EPS gateway
    • initiateSSLPayment() - SSL Commerz gateway
    • getOrderByOrderNumber() - Fetch order
    • validatePaymentLink() - Validate payment link

Data Flow: Checkout → Payment → Order Success

FRONTEND (Checkout)
├─ User adds items to cart
├─ Navigates to /checkout
├─ Enters shipping info
├─ Selects EPS payment method
├─ Clicks "Pay Now"
└─→ Calls api.createSalesOrder()

BACKEND (Order Creation)
├─ Creates SalesOrder record
├─ Sets status = 'pending'
├─ Creates OrderItems for each product
├─ Reserves inventory
└─→ Returns { orderId, orderNumber }

FRONTEND (Payment Initiation)
├─ Calls api.initiateEpsPayment(orderId)
├─ Receives { gatewayUrl, ... }
├─ Clears cart from Zustand store
└─→ Redirects: window.location.href = gatewayUrl

EPS PAYMENT GATEWAY
├─ User enters card details
├─ Completes payment
└─→ Calls backend callback with payment result

BACKEND (Payment Callback)
├─ Validates payment signature
├─ Updates order: payment_status = 'paid'
├─ Triggers financial events
└─→ Redirects: /order-success?payment_status=paid&order_id=123

FRONTEND (Order Success)
├─ Receives payment_status in query params
├─ Displays "Thank You" message
├─ Clears cart (again, for safety)
└─→ Shows order confirmation details
